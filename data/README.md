# PaySim dataset

`paysim dataset.csv` is the synthetic mobile money transaction dataset published as [PaySim1 on Kaggle](https://www.kaggle.com/datasets/ealaxi/paysim1).

The dataset is licensed under [Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/). Attribution: Edgar Alonso Lopez-Rojas, A. Elmir, and S. Axelsson, “PaySim: A financial mobile money simulator for fraud detection,” EMSS 2016. The license requires attribution and the same license for adaptations. The processed PaySim feature dataset in this project is derived from the source CSV and is shared under the same terms.

The CSV contains synthetic records. Its identifiers and fraud labels do not represent real bank customers or prove that model results transfer to real banking data. See `models/manifests/paysim_csv_manifest.json` for the dataset profile and validation notes.
